Cosa puoi fare

Organizzare secondo le tue regole

Le operazioni partono dalle cartelle e dalle categorie che configuri nell’app.

01

Anteprima

Controlla file e destinazioni proposte prima di confermare l’applicazione.

02

Organize All

Applica le regole configurate alle cartelle gestite con un comando.

03

Monitoring

Avvia e arresta il monitoraggio delle cartelle che hai configurato.

04

Undo

Quando disponibile, annulla uno spostamento registrato dall’app.

Organize All e Monitoring seguono direttamente le regole: prova prima l’anteprima su pochi file.

Prima di installare

Requisiti chiari, download verificabile

L’installer include Python 3.13.13 e Qt/PySide6 6.11.3. Microsoft Visual C++ va installato separatamente.

SistemaWindows x64 su CPU Intel o AMD. Collaudato su Windows 11 x64.
PrerequisitoMicrosoft Visual C++ v14 Redistributable x64, versione supportata più recente.

Come è stato realizzato

Direzione umana, strumenti AI

SKOrganizer 2 è un progetto di Pastoris Marco Vincenzo. Il titolare ha definito obiettivi, vincoli, scelte e prove, orchestrando strumenti di intelligenza artificiale per sviluppare e documentare il programma, poi verificando il risultato su Windows.

Gli strumenti AI appartengono al processo di sviluppo: la versione distribuita non include funzioni AI. La documentazione distingue i test completati da quelli non eseguiti e descrive le licenze delle librerie usate.
