# Testi legali nel repository

Questa cartella offre una copia consultabile dei termini dell'applicazione, degli avvisi di terze parti e dell'elenco degli archivi sorgente Qt/PySide6. I file di testo sono copiati dal corredo del candidato Windows 2.0 verificato.

Il corredo **completo** è nella cartella `LEGAL` inclusa nell'installer: contiene anche i testi integrali delle licenze, le istruzioni per sostituire le librerie LGPL e i quattro archivi dei sorgenti pubblici. I riferimenti a `LEGAL/README.txt`, `LEGAL/LICENSES` e `LEGAL/SOURCES` presenti nei termini e negli avvisi si riferiscono a quella cartella installata, non ai file del repository.

Questo repository non contiene il codice sorgente proprietario dell'applicazione. Gli archivi automatici «Source code» di GitHub non sostituiscono il corredo `LEGAL` dell'installer. Leggi [licenze e sorgenti delle librerie](../LICENSE_AND_SOURCES.md) per il contesto.
